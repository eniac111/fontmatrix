# KF6 QML wrapper libraries and QML plugin trees.
# fontmatrix.py puts libs/qt6/qtdeclarative in ignoredPackages, so Qt6Qml.dll
# is not shipped — but these libraries live inside their parent framework's
# image dir (kconfig, ki18n, …) and would otherwise be collected with a
# dangling Qt6Qml import. A QtWidgets-only app never loads them.
bin/KF6[A-Za-z0-9]*Qml\.dll
bin/declarative/.*
qml/.*

# KI18n's Transcript plugin, which links Qt6Qml for the same reason. KI18n
# loads it through QPluginLoader only when a catalogue uses scripted messages
# ({@...@}); ours are plain gettext, and a missing plugin is a warning
# ("Cannot find Transcript plugin."), not an error.
bin/kf6/ktranscript\.dll

# Symbol files — debug, never shipped.
.*\.pdb
